# 冒泡排序 (Bubble Sort)

## 算法原理

冒泡排序是一种简单的排序算法，它的工作原理如下：

1. 比较相邻的元素，如果第一个比第二个大，就交换它们两个
2. 对每一对相邻元素做同样的工作，从开始第一对到结尾的最后一对
3. 针对所有的元素重复以上的步骤，除了最后一个
4. 重复步骤1~3，直到排序完成

算法名称的由来是因为越小的元素会经由交换慢慢"浮"到数列的顶端（升序或降序排列），像气泡一样慢慢浮起。

## 优化

本实现包含一个优化：如果在某一轮遍历中没有发生任何交换，说明数组已经有序，可以提前结束算法。

## 时间复杂度

- **最坏情况**: O(n²) - 当数组完全逆序时
- **最好情况**: O(n) - 当数组已经有序时（由于优化）
- **平均情况**: O(n²)

## 空间复杂度

- O(1) - 原地排序算法，只需要常数级额外空间

## 适用场景

冒泡排序由于其 O(n²) 的时间复杂度，在处理大量数据时效率较低，通常只适用于以下场景：

- 教学演示
- 数据量较小的情况
- 对算法稳定性有要求的场景

## 代码特点

本实现提供了两个版本的冒泡排序：

1. `bubbleSort(int[] arr)` - 专门用于整数数组的排序
2. `bubbleSort(T[] arr)` - 泛型版本，可以处理任何实现了 `Comparable` 接口的类型

## 运行示例

运行 `BubbleSort.java` 将会输出：

```
整数数组排序前:
64, 34, 25, 12, 22, 11, 90
整数数组排序后:
11, 12, 22, 25, 34, 64, 90

字符串数组排序前:
[banana, apple, orange, grape, cherry]
字符串数组排序后:
[apple, banana, cherry, grape, orange]
```
